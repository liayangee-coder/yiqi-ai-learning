# 依起愛學習

依依老師的三年級上學期教學工具箱，收錄 Chrome 書籤 `05_AI／自製／3上` 中的國語、數學、社會線上網頁。

## 內容

- 國語：12 個線上網頁
- 數學：9 個線上網頁
- 社會：4 個線上網頁
- `index.html`：響應式工具箱頁面，支援科目篩選與關鍵字搜尋
- `resources.json`：依書籤標題與網址整理的清單

書籤中指向個人電腦本機檔案的頁面不在此網站中。

## GitHub Pages

此專案以 GitHub Pages 發布；首頁會載入同一資料夾中的 `resources.json`。

## 資料來源

由 `bookmarks_2026_9_28.html` 中 `書籤列／05_AI／自製／3上` 三個指定資料夾整理。書籤中其他分類與頁面不納入。
